# SK매직 상담 챗봇

SK매직 상담 흐름 50개를 체험할 수 있는 로컬 챗봇입니다. 메뉴와 선택지는 채팅 위에 표시하고, 직접 입력할 내용은 하단 메시지 입력창에서 한 항목씩 받습니다.

업무는 입력한 계약·주문 정보에 맞춰 진행됩니다. 값 채우기 버튼으로 테스트 데이터를 입력할 수 있습니다. 휴대폰 확인 단계에서는 채팅의 인증 문자에서 해당 요청의 인증번호를 확인할 수 있습니다.

## 실행

Node.js 22 이상에서 `node server.cjs`를 실행한 뒤 [로컬 챗봇](http://127.0.0.1:4328/)을 엽니다. AI 답변은 로컬 Ollama에서 실행합니다.

```sh
ollama pull qwen3:4b-instruct-2507-q4_K_M
node server.cjs
```

Ollama는 기본 주소 `http://127.0.0.1:11434/`에서 실행해야 합니다. 다른 로컬 주소나 설치된 모델을 사용할 때는 `SKMAGIC_OLLAMA_URL`과 `SKMAGIC_OLLAMA_MODEL`로 지정합니다. `index.html`을 파일로 열면 예시 상담을 오프라인으로 실행할 수 있습니다.

인증, 납부, 발송 및 상담사 연결은 예시 데이터를 사용하는 시연입니다. 실제 안내 조건은 제휴카드 상세 링크의 카드사 페이지에서 확인할 수 있습니다.

## 화면과 상담 흐름 수정

화면과 상담 로직은 `src/`에서 수정합니다. `node build.cjs`를 실행하면 배포용 `index.html`이 갱신됩니다.

인증과 주문 조회의 회귀 검사는 `node --test tests/workflows.cjs`로 실행합니다.

업무별 검증 범위와 반영 사항은 [교차검증 결과](docs/verification.md)에 정리했습니다.
